# docs/

- `PRD.md` — the single source of truth (§0 governs amendments). Every agent
  reads this first; code, comments, and chat all lose to it.
- `design/spec/` — approved design mockups: `Block Manor UI.dc.html` (screen
  compositions), `Block Manor Production Spec.dc.html` (production spec),
  `support.js` (shared support asset). Open the relevant mockup before building
  any screen (PRD §15).
- `design/` — per-section PNG exports go here when produced, named by PRD
  section: `7.11-home.png`, `8.3-daily-result.png`, …
